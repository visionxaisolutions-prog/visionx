# VisionXAI

The VisionXAI marketing site — a Bengaluru-based creative digital studio. Built with [Next.js](https://nextjs.org) (App Router).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `app/` — routes: `/` (home), `/about`, `/services`, `/work`, `/contact`
- `components/` — shared `Header`, `Footer`, `ContactForm`, and small reusable icons
- `app/globals.css` — global stylesheet (shared across all pages)
- `public/` — large decorative SVG illustrations (hero globe, page decor)
- `legacy-html/` — the original static HTML this project was migrated from, kept for reference

## Build

```bash
npm run build
npm start
```
